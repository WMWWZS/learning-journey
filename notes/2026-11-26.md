## 完整 CMake 最小工程

```cmake
cmake_minimum_required(VERSION 3.21)
project(app LANGUAGES CXX)

find_package(Qt6 REQUIRED COMPONENTS Widgets)
qt_standard_project_setup()                    # 只打开 AUTOMOC/AUTOUIC
set(CMAKE_AUTORCC ON)                          # AUTORCC 要单独开

qt_add_executable(app main.cpp)
target_link_libraries(app PRIVATE Qt6::Widgets)
```

Qt6 的 `qt_standard_project_setup()` 只打开 **AUTOMOC / AUTOUIC**；`AUTORCC` 要单独 `set(CMAKE_AUTORCC ON)` 或改用 `qt_add_resources()`（Qt 6.10 源码 Qt6CoreMacros.cmake 里就是 `foreach(auto_set IN ITEMS MOC UIC)`）。

## 学到的 3 个点

1. CMake 四行：`find_package` → `qt_standard_project_setup` → `qt_add_executable` → `target_link_libraries`。
2. 三个自动工具：AUTOMOC（Q_OBJECT）、AUTOUIC（.ui）、AUTORCC（.qrc）。
3. Queued 链路：emit → activate → 打包 `QMetaCallEvent` → postEvent 到接收线程 → exec 取出 → notify → event → placeMetaCall → 槽。
