## 最小 CMake 工程

```cmake
cmake_minimum_required(VERSION 3.21)
project(app LANGUAGES CXX)

find_package(Qt6 REQUIRED COMPONENTS Widgets)
qt_standard_project_setup()                    # 打开 AUTOMOC/AUTOUIC/AUTORCC

qt_add_executable(app main.cpp)
target_link_libraries(app PRIVATE Qt6::Widgets)
```

## 学到的 3 个点
1. Qt6 CMake：`find_package` + `qt_standard_project_setup()` + `qt_add_executable` + `target_link_libraries`。
2. 三个自动工具：AUTOMOC（Q_OBJECT）、AUTOUIC（.ui）、AUTORCC（.qrc）。
3. `windeployqt` 补齐运行时依赖；缺 `platforms/qwindows.dll` → 平台插件初始化失败。
