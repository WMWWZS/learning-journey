## 示例页：播放器 · 点播放（对照用）

| 项 | 内容 |
| :-- | :-- |
| 触发 | `PlayerWidget::onPlayPause`（点播放按钮） |
| 调状态 | `m_playing = true`；按钮文字切"暂停" |
| 跨线程 | UI 线程 `PlaybackTask::play()` → 队列连接 → 解码线程清 `m_paused`、唤醒 `QWaitCondition` |
| 数据 | `cap.read()` → `cv::Mat` → `matToImage` 转 `QImage`（**深拷贝**）→ `emit frameReady(img)` |
| 消费 | UI 线程 `onFrameReady` → `label->setPixmap`；`positionChanged` 更新滑块（拖动中忽略） |
| 回收 | 关窗 → `stop()` 置原子标志 → `quit()` + `wait()` → `deleteLater()`；`VideoCapture` 在线程内 release |

**对象表（播放器）**

| 对象 | 谁创建 | 谁持有 | 在哪个线程 | 谁销毁 |
| :-- | :-- | :-- | :-- | :-- |
| `PlaybackTask` | `PlayerWidget` | `QThread`（moveToThread） | 解码线程 | 停止后 delete |
| `QThread` | `PlayerWidget` | `PlayerWidget` | — | `wait()` 后 delete |
| `QSlider/QTimer` | `PlayerWidget` | `PlayerWidget`（父子对象树） | UI 线程 | 父对象析构自动删 |

**状态表（播放器）**

| 状态 | `m_playing` | `m_paused` | 滑块 | 按钮文字 | 帧还在读吗 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 初始 | false | false | 0 | 播放 | 否 |
| 播放中 | true | false | 跟帧走 | 暂停 | 是 |
| 暂停 | true | true | 不动 | 继续 | 是（阻塞等待） |
| 拖动中 | true | — | 用户控制 | — | 是（忽略同步） |
| 结束 | false | false | 末尾 | 重播 | 否 |

## 小提示

- **时序图**别画全项目，一次只画"一个动作"（点播放、触发录制、点截图）
- **对象表**先查 `new`，再查谁 `delete`/`deleteLater`，对不上就是泄漏风险
- **状态表**写完拿它去核对代码里的 `if` 分支，能发现漏处理的状态
- 图/表贴在笔记里，**重写代码时只允许看它，不许看源码**
