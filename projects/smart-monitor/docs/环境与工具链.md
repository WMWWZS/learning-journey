# 环境与工具链（本机实测）

> 本文件记录你电脑上 **Qt 6.10.1 MinGW** 环境怎么配 OpenCV。
> 更新时间：2026-11-12

## 一、本机现状（已探测）

| 项 | 位置 / 版本 |
| :-- | :-- |
| Qt | `E:\Qt\6.10.1\mingw_64`（Qt 6.10.1，MinGW 64-bit kit） |
| MinGW 编译器 | `E:\Qt\Tools\mingw1310_64\bin\g++.exe`（**GCC 13.1.0**） |
| CMake | `E:\Qt\Tools\CMake_64\bin\cmake.exe` |
| Ninja | `E:\Qt\Tools\Ninja\ninja.exe` |
| Qt Creator | `E:\Qt\Tools\QtCreator` |
| Visual Studio | **未安装** |
| OpenCV | **未安装** |
| 干扰项 | `C:\mingw64\bin\g++.exe` 也在 PATH 里 —— **不要用它**，版本和 Qt 不一致 |

## 二、最大的坑（先说结论）

**OpenCV 官网的 Windows 预编译包是 MSVC 编译的，和你的 MinGW 编译器 ABI 不兼容。**
直接拿 `opencv-4.x-windows.exe` 配 Qt MinGW 工程，会在链接阶段炸：

```
undefined reference to `cv::imread(...)`
cannot find -lopencv_world4100
```

正确做法只有两条：

- **方案 A（推荐）：用 Qt 自带的 MinGW 13.1 源码编译 OpenCV**
- 方案 B：装 Visual Studio 2022 Build Tools + 用 Qt Maintenance Tool 装 MSVC kit，再配官方 OpenCV 包

下面写方案 A，方案 B 放在最后备选。

## 三、方案 A：源码编译 OpenCV（Qt MinGW）

预计时间：**20–40 分钟**（取决于 CPU），占用磁盘约 1.5 GB。

### 1. 下载源码

- 打开 https://github.com/opencv/opencv/releases/tag/4.10.0
- 下载 **Source code (zip)**
- 解压到 `E:\opencv-src`（路径不要有中文和空格）
  - 解压后应存在 `E:\opencv-src\CMakeLists.txt`

### 2. 用 Qt 自带工具配置（命令行一行）

在 **Qt 6.10.1 MinGW 命令行**里执行（或用 PowerShell，路径全写死）：

```powershell
E:\Qt\Tools\CMake_64\bin\cmake.exe -S E:\opencv-src -B E:\opencv-build -G Ninja `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_C_COMPILER=E:/Qt/Tools/mingw1310_64/bin/gcc.exe `
  -DCMAKE_CXX_COMPILER=E:/Qt/Tools/mingw1310_64/bin/g++.exe `
  -DCMAKE_MAKE_PROGRAM=E:/Qt/Tools/Ninja/ninja.exe `
  -DCMAKE_INSTALL_PREFIX=E:/opencv-mingw `
  -DBUILD_opencv_world=ON `
  -DBUILD_TESTS=OFF -DBUILD_PERF_TESTS=OFF -DBUILD_EXAMPLES=OFF `
  -DBUILD_JAVA=OFF -DBUILD_opencv_python3=OFF `
  -DWITH_FFMPEG=OFF -DWITH_OPENCL=OFF -DWITH_IPP=OFF
```

关键点：
- 编译器必须是 `E:/Qt/Tools/mingw1310_64` 下的（GCC 13.1），不是 `C:\mingw64`
- `BUILD_opencv_world=ON` 把库合成一个，工程里少配一堆链接
- `WITH_FFMPEG=OFF` 省事；MJPG/AVI 录制 OpenCV 自带编码器，够用

### 3. 编译 + 安装

```powershell
E:\Qt\Tools\CMake_64\bin\cmake.exe --build E:\opencv-build --target install -j 8
```

### 4. 验证产物

```text
E:\opencv-mingw\
├── include\opencv2\...
└── x64\mingw\
    ├── bin\opencv_world4100.dll
    └── lib\libopencv_world4100.dll.a
    └── lib\cmake\opencv4\    ← CMake 会在这里找配置
```

### 5. 在 Qt Creator 里用

工程 `CMakeLists.txt` 里加：

```cmake
find_package(OpenCV REQUIRED)          # 需要先设 OpenCV_DIR 或 CMAKE_PREFIX_PATH
include_directories(${OpenCV_INCLUDE_DIRS})
target_link_libraries(你的目标 PRIVATE Qt6::Widgets Qt6::Sql ${OpenCV_LIBS})
```

`OpenCV_DIR` 指到：

```text
E:/opencv-mingw/x64/mingw/lib/cmake/opencv4
```

（Qt Creator → 项目 → 构建设置 → CMake → 添加 `OpenCV_DIR` 这个变量即可）

### 6. 运行期 DLL

程序跑起来需要 `opencv_world4100.dll`：

- 把 `E:\opencv-mingw\x64\mingw\bin` 加进系统 PATH，**或**
- 把 dll 复制到 exe 同目录

发布时 Qt 用 `windeployqt` 收 Qt 的 dll，OpenCV 的 dll 要自己复制过去。

## 四、方案 B：MSVC 路线（备选）

如果编译源码反复失败，可以换这条路（下载量大，约 5 GB）：

1. 装 **Visual Studio 2022 Build Tools**（勾选"使用 C++ 的桌面开发"）
2. Qt Maintenance Tool 里加装 **Qt 6.10.1 MSVC 2022 64-bit**
3. 下载 OpenCV 官方 `opencv-4.10.0-windows.exe`，解压即用
4. Qt Creator 里改用 MSVC kit 新建工程

## 五、摄像头 / 录制注意

| 事项 | 建议 |
| :-- | :-- |
| 采集后端 | `cv::VideoCapture(0, cv::CAP_DSHOW)` 在 Windows 更稳 |
| 录制编码 | `MJPG` + `.avi`（OpenCV 自带编码器，不需要 ffmpeg） |
| 中文路径 | 避免：OpenCV 的 `imwrite`/`VideoWriter` 对中文路径不稳 |
| 调试顺序 | 先用一个 **本地 mp4** 测试读取，再接摄像头 |
| 无摄像头 | 通道 2–4 播放本地视频（需求文档也允许） |

## 六、常见报错对照

| 报错 | 原因 / 解法 |
| :-- | :-- |
| `cannot find -lopencv_world4100` | 用了 MSVC 版 OpenCV；必须用方案 A 自编译 |
| `undefined reference to cv::...` | 同上（ABI 不兼容） |
| `Could not find a package configuration file provided by "Qt6"` | 加 `-DCMAKE_PREFIX_PATH=E:/Qt/6.10.1/mingw_64` |
| `0xc000007b` 启动失败 | 32/64 位 dll 混用；检查 PATH 里旧 dll |
| `No such file: mfapi.h` 等 | 用了 MSVC 才有的头；确认用的是 MinGW 编译 |
| Qt Creator 构建报 `The kit ... is not valid` | 检查 kit 的编译器是否指向 `E:\Qt\Tools\mingw1310_64` |
