## 风险与兜底

| 风险 | 兜底 |
| :-- | :-- |
| 没有摄像头 | 用录像文件当通道源（项目已支持） |
| YOLO 模型下载慢 | 降级 HOG+SVM（OpenCV 自带） |
| 时间不够 | 先保 D1/D2/D3 检测链，D6 的日志/设置可简化 |
| 打包失败 | 先录演示视频，dll 清单按 `环境与工具链.md` 手动复制 |
