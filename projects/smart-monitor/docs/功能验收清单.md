# 功能验收清单（对照需求文档）

> 用法：每做完一项，把 `[ ]` 改成 `[x]`。
> 优先级：**P0 = 必须演示；P1 = 尽量；CUT = 一周内不做（写进 README 差距）**

## 1. 登录 / 退出

- [ ] **P0** 启动进主页面，未登录只能实时预览
- [ ] **P0** 右上角"登录"按钮 → 弹登录框
- [ ] **P0** 账号 6–10 位数字/字母、密码 6–8 位校验
- [ ] **P0** 空账号或空密码 → 提示"账号或密码不能为空"
- [ ] **P0** 密码隐藏显示 + 明/密文切换按钮
- [ ] **P0** 验证码（字母不区分大小写），输错自动刷新
- [ ] **P0** 数据库里密码存 **MD5**
- [ ] **P1** 连续 3 次失败锁定 10 分钟
- [ ] **P0** 登录成功回主页面，右上角显示用户信息
- [ ] **P0** 退出后回未登录状态

## 2. 设备接入与预览

- [ ] **P0** 1–4 路摄像头本地接入（或用视频文件代替）
- [ ] **P0** 默认四画面分割
- [ ] **P0** 未接入通道播放本地视频
- [ ] **P0** 单画面 / 四画面切换按钮

## 3. 本地存储与回放（需登录）

- [ ] **P0** 存储路径可配置，默认本地指定目录
- [ ] **P0** 视频自动录制，60s 分段（测试用）
- [ ] **P0** "普通视频回看"标签：按日期+时间段（精确到分钟）检索
- [ ] **P0** 按通道检索
- [ ] **P0** 结果显示"时间、通道、事件类型"
- [ ] **P0** 播放 / 暂停 / 继续
- [ ] **P0** 2x / 4x 快进
- [ ] **P0** 进度条拖拽定位
- [ ] **P0** 回放时"抓拍"保存当前帧
- [ ] **P1** 硬盘空间 ≤10% 时底部提示"硬盘空间低（剩余 XX%）"并记日志

## 4. 移动目标侦测

- [ ] **P0** 单通道开启侦测（多通道可关闭）
- [ ] **P0** 检测到人 → 绿色框标出（基础要求：人体检测）
- [ ] **P0** 触发瞬间保存当前帧
- [ ] **P0** 自动录移动目标视频 60s（先停原录制）
- [ ] **P0** "移动侦测回看"标签只查侦测视频

## 5. 特征图片截取与预览

- [ ] **P0** 自动截取 3 张，命名 `异常_通道X_YYYYMMDDHHMMSS_1/2/3.jpg`
- [ ] **P0** 手动截取：默认名 `手动_通道X_YYYYMMDDHHMMSS.jpg`，可改名、选目录
- [ ] **P0** "图片管理"页：左侧按事件时间/通道筛选
- [ ] **P0** 右侧 3 行 3 列缩略图，时间倒序
- [ ] **P0** 点缩略图进大图；滚轮缩放 0.5–2 倍；拖动；左右箭头切换
- [ ] **P1** 大图下方"查看对应视频"→ 跳到关联视频并定位时间点
- [ ] **P0** 选中图片支持删除（异常图二次确认"确定删除该异常图片及关联日志？"）
- [ ] **P1** 导出：选 USB 设备路径，批量导出选中图片

## 6. 系统配置

- [ ] **P1** 设置页：视频/图片存储位置
- [ ] **P1** 采集时间间隔
- [ ] **P1** 摄像头通道和名称（如"客厅摄像头"）

## 7. 日志管理（需登录）

- [ ] **P1** 操作日志：操作者 / 时间 / 功能
- [ ] **P0** 异常日志：事件 ID、触发时间、通道、类型、关联图片数、视频路径
- [ ] **P1** 日志按时间倒序，支持通道/时间筛选
- [ ] **P1** 点日志条目可看关联图片/视频
- [ ] **P1** 单条删除 + 批量删除（"删除 30 天前"/"指定时间范围"）

## 8. 非功能需求（交付说明里写）

- [ ] **P1** 密码 MD5 存储（文档安全需求）
- [ ] **P1** 登录失败 3 次锁定 10 分钟
- [ ] **P1** 磁盘容量告警
- [ ] **P0** 关键操作二次确认（保存配置、删除记录）
- [ ] **CUT** 响应时间 ≤1s / 查询 ≤3s（演示时提一下即可）
- [ ] **CUT** 10 万条数据压测
- [ ] **CUT** 每日自动备份

## 演示脚本（D7 用）

1. 启动 → 未登录，四画面预览
2. 登录（故意输错密码一次 → 提示；再输对）
3. 切单画面 → 移动侦测触发 → 绿框 + 自动截图 + 自动录制
4. 回放：选时间/通道 → 播放 → 2x → 拖进度 → 抓拍
5. 图片管理：3×3 缩略图 → 大图缩放 → 删除二次确认
6. 日志：查看异常事件 → 筛选
7. 设置：改存储路径 → 保存二次确认
