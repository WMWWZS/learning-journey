# 智能监控系统（学习项目 · 一周 MVP）

> 需求来源：《智能监控系统项目实战指南》XTZNP-2026-Smart_Monitor v1.0（12 页，星途智能 2026）
> 原则：**代码自己写**，这里只放计划、环境说明和验收清单。

## 一句话介绍

Windows 本地运行的 1–4 路摄像头监控：实时预览、管理员登录、录制与回放、移动侦测自动截图、图片管理、事件日志。不联网、不依赖云。

## 一周交付范围（MVP）

| 优先级 | 功能 | 说明 |
| :-- | :-- | :-- |
| **P0** | 多路预览 | 1–4 路接入；单/四画面切换；无摄像头通道播放本地视频 |
| **P0** | 登录 | 账号密码（MD5）+ 验证码 + 3 次失败锁定；右上角登录态 |
| **P0** | 录制与回放 | 60s 分段录制；按时间/通道筛选；播放/暂停/2x/4x/进度拖拽/抓拍 |
| **P0** | 移动侦测 | 单通道开启；绿色框标出人体；触发后存 3 张图 + 自动录 1 分钟 + 事件日志 |
| **P0** | 图片管理 | 3×3 缩略图、筛选、大图预览（0.5–2x 缩放）、左右切换、删除二次确认、导出 |
| **P1** | 事件日志 | 筛选/查看/删除；关键操作记录 |
| **P1** | 系统设置 | 存储路径、采集间隔、通道名称 |
| **P1** | 磁盘告警 | 剩余空间 ≤10% 提示并记日志 |
| **不做** | MySQL | 一周 MVP 先用 **SQLite**，交付后可选迁移 |
| **不做** | H.264 | OpenCV 官方不带 H.264 编码器，用 **MJPG + AVI** 兜底 |
| **不做** | YOLO 训练 | 用预训练模型（OpenCV DNN）或 HOG+SVM 兜底，不训练 |

## 技术栈

| 项 | 版本 / 说明 |
| :-- | :-- |
| 语言 | C++17 |
| UI | Qt 6.10.1（MinGW 64-bit kit） |
| 视觉 | OpenCV 4.x —— **必须用 Qt 自带 MinGW 自行编译**（官方包是 MSVC 的，链接不上） |
| 数据库 | SQLite（Qt 自带 QSQLITE 驱动） |
| 构建 | CMake + Ninja / Qt Creator |
| 运行平台 | Windows 10/11 x64 |

> 环境搭建细节和踩坑说明见 **`docs/环境与工具链.md`**。
