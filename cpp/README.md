# C++ 练习

按 **年-月 / 日期-主题** 归归档，例如：

```text
cpp/
└── 2026-11/
    ├── 11-12-basics/        # 引用、重载、动态内存
    ├── 11-13-date/          # Date 类
    └── 11-14-string/        # 深浅拷贝、String 类
```

规则：
- 每个练习一个文件夹，里面放源码 + 一个简短 README（说明练了什么、卡在哪）
- 编译产物（`*.exe`、`build/`）不进仓库
- 每天练完把能跑通的版本提交，commit message：`cpp: 引用与重载练习`
